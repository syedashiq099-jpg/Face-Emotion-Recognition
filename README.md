# Face-Emotion-Recognition

Developed an end-to-end computer vision and deep learning system that detects human faces from a live video stream and classifies real-time facial expressions into seven primary emotion categories (Happy, Sad, Angry, Surprised, Neutral, Fear, Disgust) using a Convolutional Neural Network (CNN) and OpenCV.

## 🛠️ Technologies Used

- **Python** – Core programming language
- **OpenCV** – Real-time webcam capture and video frame processing
- **Facial Emotion Recognition** – Emotion detection and classification
- **EmotionRecognition Library** – Facial emotion recognition functionality
- **Webcam** – Real-time video input

## ✨ Key Features

- 🎥 **Real-Time Webcam Processing** – Captures and processes live video using the webcam.
- 👤 **Face Detection** – Detects the face from the live camera feed.
- 😊 **Emotion Recognition** – Identifies the facial emotion from the detected face.
- 🧠 **AI-Based Analysis** – Uses a pre-trained facial emotion recognition model for emotion classification.
- ⚡ **Real-Time Processing** – Continuously analyzes video frames and updates the detected emotion.
- 🖥️ **Live Visualization** – Displays the processed camera feed in real time.
- 💻 **CPU-Based Processing** – Runs the emotion recognition model using CPU processing.
- ❌ **Easy Exit** – Press the `ESC` key to safely stop the application.

## 🎯 Project Objective

The objective of this project is to develop a real-time facial emotion recognition system that can analyze facial expressions through a webcam and identify the corresponding emotion.

## ⚙️ How It Works

1. The webcam captures live video frames.
2. Each frame is passed to the facial emotion recognition model.
3. The system detects and analyzes the facial expression.
4. The detected emotion is displayed on the live video window.
5. The application continues processing frames until the `ESC` key is pressed.
